# 📚 Desk and Study Essentials E-Commerce App

A full-stack e-commerce application for managing and selling desk and study essentials. Built using **Python** and **Django**, this project provides a structured platform for users to browse products, manage their accounts, and for admins to manage inventory efficiently.

---

## ⚡ Features

### User-Facing
- Browse products by category
- User account registration 

### Admin-Facing
- Add, update, and delete products
- Manage user contact information
- Dashboard to monitor store activity
---

## 🛠 Technologies Used
- **Backend:** Python, Django
- **Frontend:** Django Templates, HTML, CSS, Bootstrap
- **Database:** SQLite
- **Other:** Media file handling, Git for version control
